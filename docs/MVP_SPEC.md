# Зафиксированный объём первого MVP

## Направление

- Сейшелы;
- 20-30 заранее выбранных отелей;
- три источника: Maldives Bonus, Resort Holiday, Мальдивиана.

## Параметры поиска

- только проживание;
- без перелёта;
- без трансфера;
- 2 взрослых;
- заданная дата заезда;
- заданное количество ночей;
- первая доступная категория.

## Правило первой доступной категории

Робот получает первую доступную категорию каждого источника, но сравнивает цены только тогда, когда категории вручную или автоматически подтверждены как одинаковые.

Пример:

- `Standard Room` и `Standard Room` - сравниваем;
- `Standard Room` и `Deluxe Room` - не сравниваем;
- результат для разных категорий помечается как `нет сопоставимого предложения`.

## Обязательные совпадающие поля

1. отель;
2. дата заезда;
3. количество ночей;
4. состав туристов;
5. категория номера;
6. питание;
7. наличие трансфера;
8. включение налогов;
9. валюта.

## Результаты

- лучшая цена;
- лучший источник;
- абсолютная разница;
- процентная разница;
- цветовой статус;
- Excel;
- PDF;
- история цен;
- журнал ошибок.
