# Что требуется для подключения реальных сайтов

Для безопасности желательно создать временные тестовые учётные записи, а не передавать основные рабочие пароли.

## По каждому из трёх источников

1. Адрес страницы, где выполняется поиск.
2. Тестовый логин.
3. Тестовый пароль.
4. Нужна ли дополнительная SMS/почтовая проверка.
5. Один ручной расчёт с подтверждённым результатом:
   - название отеля на сайте;
   - дата заезда;
   - ночей;
   - 2 взрослых;
   - категория номера;
   - питание;
   - цена;
   - валюта;
   - включены ли налоги;
   - включён ли трансфер.
6. Скриншот результата или сохранённая страница.
7. Подтверждение, что автоматизированный вход и получение цен разрешены владельцем аккаунта.

## Общие данные

- список 20-30 отелей Сейшел;
- даты и количество ночей для первого запуска;
- желаемое расписание;
- адрес почты или Telegram для отчётов;
- пороги цветов, если стандартные 5% и 10% не подходят.
